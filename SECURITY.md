# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, pull requests,
or the GAMS Forum.

Instead, send an email to [support@gams.com](mailto:support@gams.com) with "GAMSPy security" in
the subject line. Please include:

- The GAMSPy version (`gamspy --version`), Python version, and operating system.
- A description of the vulnerability and its impact.
- Steps or a minimal script to reproduce it.

We will acknowledge your report, keep you informed of our progress, and credit you in the
release notes if you wish. Please give us a reasonable amount of time to release a fix before
disclosing the issue publicly.

## Scope

Vulnerabilities in the GAMS system, its solvers, or GAMS Engine should also be sent to
[support@gams.com](mailto:support@gams.com), and we will forward them as needed.
